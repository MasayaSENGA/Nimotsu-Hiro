# にもつひろ 📦

伝票番号を Google で検索すると、検索結果の先頭にヤマト運輸・佐川急便・日本郵便の追跡ページへのリンクを差し込む Chrome 拡張機能です。

「この番号どこの運送会社だっけ」と各社のサイトを開き直す手間をなくします。

## インストール

### Chrome ウェブストアから

Chrome ウェブストアで公開しています。ストアのページで「Chrome に追加」を押すだけでインストールできます。

https://chromewebstore.google.com/detail/ikjkommgenpjhpkoflciigpmmnkbakgp

2026年10月5日時点でストアに公開しているのは 1.2 で、2.0（google.co.jp への対応、全角ハイフンへの対応、チェックディジットによる判定など）を審査中です。このリポジトリの 2.0.1 は、2.0 から `manifest.json` の `homepage_url` を削除しただけの版で、2.0 の審査が終わってから提出します。

### 開発者モードで読み込む

ストアを使わずに開発中のコードを試す場合は、開発者モードで読み込みます。

1. このリポジトリを clone する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選択する

## 使い方

Google で伝票番号を検索するだけです。ハイフンや空白、全角数字が混ざっていても認識します。

```
1234-5678-9013
１２３４５６７８９０１３
１２３４－５６７８－９０１３
EM123456789JP
```

## 検出のしくみ

クエリを正規化（全角→半角、ハイフン・空白の除去）したうえで、以下の条件に該当する運送会社のボタンだけを表示します。該当がなければ何も表示しません。

| 運送会社 | 条件 |
| --- | --- |
| ヤマト運輸 | 12桁 かつ モジュラス7チェックディジットが一致 |
| 佐川急便 | 10〜14桁（12桁のときのみモジュラス7を適用） |
| 日本郵便 | 国内 11〜13桁 / 国際 S10形式（例: `EM123456789JP`） |

モジュラス7チェックディジットは、**先頭11桁を数値として7で割った余りが末尾1桁と一致する**というルールです。ヤマト運輸と佐川急便の12桁番号で利用されており、伝票番号ではない12桁の数字をヤマト運輸・佐川急便の番号と誤って判定することを大きく減らします。日本郵便の番号にはチェックディジットがないため、桁数のみで判定しています。

なお、判定は番号の形式だけで行うため、携帯電話番号（11桁）など伝票番号ではない数字でもボタンが表示されることがあります。

## 権限について

- 追加の permissions は一切要求しません
- 動作するのは `https://www.google.com/search*` と `https://www.google.co.jp/search*` のみです
- 伝票番号を含むデータを収集したり、自動で外部に送信したりすることはありません（検索語は判定のためにブラウザ内で使うだけです）
- ボタンを押したときだけ、追跡ページを開くために、番号が URL の一部としてその運送会社に渡ります。リンクには `rel="noopener noreferrer"` を付与しているため、検索結果ページの URL（検索語）がリファラとして送られることはありません

インストール時に Chrome は「www.google.com 上にあるデータの読み取りと変更」といった趣旨の確認を表示します。この確認はサイト（ホスト名）単位の表示で、`/search` のようなパスまでは示されません。また、国別のドメインだけが違う www.google.co.jp は、www.google.com にまとめて表示されます。実際に動作するのは、上記の 2 つのホストの検索結果ページだけです。

プライバシーポリシーは https://privacy.love-live.jp/ で公開しています。全拡張機能で共通のポリシーで、このリポジトリとは別の、プライバシーポリシー用のリポジトリで管理しています。

## ファイル構成

```
manifest.json   拡張機能のマニフェスト（Manifest V3）
content.js      検出とリンク挿入のロジック
content.css     差し込むカードのスタイル
icons/          アイコン（16 / 48 / 128px）
LICENSE         ライセンス（MIT）
scripts/        配布用 ZIP の作成とストア画像の生成スクリプト
store/          Chrome ウェブストアの掲載画像（assets/）と、その元になる HTML（src/）
```

ストアに提出する ZIP に入るのは `manifest.json`・`content.js`・`content.css`・`icons/`・`LICENSE` だけです。

## 開発メモ

- スタイルは `content_scripts.css` として宣言しています。ページ側の DOM に `<style>` を注入すると Google の Content Security Policy の影響を受けるおそれがあるためです。
- Google の検索結果はページ遷移なしで書き換わるため、Navigation API の `navigate` イベントで再描画します。非対応環境では MutationObserver にフォールバックします。
- 挿入先は `#rcnt` → `#center_col` → `main` の順に探します。Google の仕様変更に備えた多段フォールバックです。

## Chrome ウェブストアへの公開

アップロード用の ZIP は、リポジトリのルートで次のコマンドを実行すると `dist/nimotsu-hiro-<version>.zip` に作成されます。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1
```
